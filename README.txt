PULSE — LSMG × LEDGERA
Netlify-ready PWA prototype

UPLOAD:
1. Log in to Netlify.
2. Use the “Want to deploy a new project?” drag-and-drop box.
3. Upload pulse-netlify.zip OR unzip it and drag the pulse-netlify folder.
4. Netlify will publish it immediately on a temporary .netlify.app URL.

WHAT WORKS IN THIS PROTOTYPE:
- PULSE splash/branding
- FEED
- WATCH demo channels
- PREDICT with local point scoring + saved calls
- CONNECT creative cards + demo mutual matches
- ME profile with scores/matches
- Search modal
- Local storage persistence
- Installable PWA manifest/service worker
